## New Facts Learned

1. **GBrain `bun build` vs `bun run` distinction** — `bun run src/cli.ts` works; `bun build` fails on Node.js builtins. Build is for browser targets, run is for Node/Bun targets.
2. **X post leak root cause** — `trending_ai_post_generator.py` passed `CREDENTIALS` (file path to `.x-api.json`) as `argv[2]` to `x-post-file.mjs`. The mjs expected `argv[2]` = tweet text file path. Result: raw JSON credentials posted to @CertainLogicAI. Fix: remove `CREDENTIALS` arg, let mjs load its own credentials via `loadCredentials()`.
3. **ClawHub `list` CLI has stale cache** — Dashboard shows 3 skills delisted correctly; `clawhub list` still returns them. Dashboard is source of truth.
4. **Subagent killed 200-case Hermes benchmark** — Real test suite lost forever on 2026-04-24 due to Phase D context flush. Reconstructed with honest assessment. Critical learning: never let subagents touch benchmark data unless explicit protect flag set.
5. **Blog publish bug** — `latest_urls.json` contains `{"published": "PUBLISHED"}` for all 5 posts. Publish script is not capturing real deployment URLs from Cloudflare.
