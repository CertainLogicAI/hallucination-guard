============================================================
  STEP 3: Write Tamper-Evident Page
============================================================

Every write generates an HMAC-SHA256 signature.
The signature is stored in the page's frontmatter.
If anyone modifies the page, the signature won't verify.
    
  Slug: demo/patient-record-012632
  Write success: True
  SHA-256 Hash: 4912152e93c4b6e9...
  HMAC Signature: 5db041420ac082e0...
  Audit ID: cb9c2cb860cfdb62

============================================================
  STEP 4: Verify Page Integrity
============================================================

Verification performs TWO checks:
1. SHA-256 hash match (content hasn't changed)
2. HMAC signature match (provenance is valid)
    
  Hash verified: True
  HMAC verified: True
  Stored hash:   4912152e93c4b6e9...
  Computed hash: 4912152e93c4b6e9...
  HMAC sig:      5db041420ac082e0...
  ✅ PASS — Full verification (hash + HMAC)

============================================================
  STEP 5: Security - Blocked Operation
============================================================

Intent layer blocks operations not in the 'allowed' list.
Medical domain forbids 'brain.sync' - this should be BLOCKED.
    
  Command: brain.sync
  Blocked: True
  Reason: Command 'brain.sync' forbidden by intent for domain 'medical'
  ✅ PASS — Intent blocked unauthorized sync

============================================================
  STEP 6: Audit Trail
============================================================

Every operation is logged to an append-only audit file.
This creates a non-repudiable record of all agent actions.
    
  [01:26:35] brain.get_page | N/A
  [01:26:35] brain.get_page | True
  [01:26:35] brain.sync | N/A
