## Evaluation Process (Before Offering)

### Step 1: Values Alignment Check (30 min call)
- Share Brain Capture Policy. If they laugh or resist, end call.
- Ask: "What's your view on shipping unverified software?" Wrong answer = done.
- Ask: "Would you work without salary for 6 months for equity?" No = done.

### Step 2: Technical Deep Dive (1 hour)
- Show them the beta page code. Ask how they'd improve it.
- Show them the deterministic brain. Ask what they'd build on top.
- If they only want to replace it with an LLM, done.

### Step 3: Working Session (1 day)
- Give them a real task: "Improve the beta onboarding flow"
- See how they document, how they verify, how they communicate
- If they don't write docs or tests, done.

### Step 4: Anton Gut Check
- Do they feel like a colleague, not an employee?
- Would Anton trust them with investor calls?
- Would Anton trust them with our codebase?

### Step 5: Brain Capture + Sleep On It
- Store all evaluation notes in brain under `family/work/co_founder_evals/`
- Minimum 48 hours before any offer
