# CertainLogicAI Reply Strategy

## Why Replies Work
- Algorithm pushes reply-givers to followers of the original poster
- Replies show expertise without being "that guy" who only self-promotes
- Each reply is a micro-demo of the product (if done right)

## Reply Types That Convert

### 1. The "Pattern Interrupt" (questions only)
When someone asks "What's the best AI tool for X?"
```
"Everyone says ChatGPT. 

But what happens when it hallucinates and your client finds out? 😤

I built a guard for that. Free. Zero config.

DM if curious."
```

### 2. The "Agree + Add Fire"
When someone complains about AI reliability:
```
"This is exactly why I stopped trusting "Done" from agents.

Built a tracker that shows you WHAT actually executed.

Green = proven. Red = not. No more surprises.
\n🔗 clawhub link"
```

### 3. The "Show Don't Tell"
When someone asks how to do something our product does:
```
"Here's how I'd solve that in 30 seconds:

[curl command or 2-line code]

No LLM needed. Brain has the fact. Instant. Free.

Want the full system?"
```

### 4. The "Pain Mirror"
When someone describes a problem we solve:
```
"Tired of this exact thing. 😤

So I built the fix. Open source. 

MIT license because gatekeeping tools is corny.

DM me 'guard' and I'll send the install."
```

## Rules
- **Never** reply with just a link (looks spammy)
- **Always** add value first, pitch second
- **Keep replies under 280 chars** when possible
- **End with question or CTA** that invites DM
- **Match the energy** of the original post
- **Max 5 replies per hour** (don't look automated)

## Voice Checklist
- ✅ Direct, slightly frustrated at the problem
- ✅ First-person: "I built this" not "We built this"
- ✅ Short sentences
- ✅ Mix emojis: 🟢🔴😤
- ✅ "Done" in quotes when mocking AI agent promises
- ✅ "Gaslit" when talking about AI reliability

## Tracking
- Reply to posts from: AI engineers, indie hackers, devs frustrated with AI
- Avoid: Corporate accounts, agencies, bootstrap bros
- Time: 9-11 AM CST and 1-3 PM CST (best engagement)
