# X Posting Framework — "The HSCR System"

## Hook → Story → CTA → Repeat

Based on Ship30for30 thread methodology, Justin Welsh's 1-3-1, Hormozi's content matrix, and Hootsuite's engagement-first principles. Adapted for build-in-public solopreneurs.

---

## Core Principle: The Algorithm Rewards Engagement, Not Quality

X doesn't show "good" tweets. It shows tweets that generate replies, bookmarks, and time-on-tweet. Structure > brilliance.

---

## The 5 Tweet Types (Rotate Daily)

### Type 1: Hook Tweet (Curiosity Gap)
**Pattern:** [Surprising number/claim] + [Unexpected twist]
**Goal:** Stop the scroll. Create a gap between what they know and what you know.

**Templates:**
```
I [did X] and [unexpected result].

Here's what I learned:
```
```
[Number] [things] that [audience] gets wrong about [topic].

Number [N] will surprise you:
```
```
Most people [common approach].

The ones making money [contrarian approach].
```

**Examples for us:**
- "I audited the top 10 OpenClaw skills. 3 had critical security flaws. One routes your data through their servers."
- "I spent $50 in AI tokens on Day 1. Here's how I turned that into a product."
- "Most people treat AI agents like chatbots. The ones making money treat them like employees."

---

### Type 2: Proof Tweet (Show, Don't Tell)
**Pattern:** Real output / screenshot / numbers + brief context
**Goal:** Build credibility through evidence. Terminal output > claims.

**Templates:**
```
Just ran [tool] on [target].

Results:
[paste real output]

[One-line insight]
```
```
Day [N] numbers:
- [metric 1]
- [metric 2]
- [metric 3]

[What it means]
```

**Examples for us:**
- Terminal output from security scanner
- GEO audit score on a real site
- Pipeline tracker status
- Daily build-in-public numbers

---

### Type 3: Lesson Tweet (Build-in-Public Insight)
**Pattern:** [Mistake or discovery] → [What I learned] → [What I'd do differently]
**Goal:** Provide value. These get bookmarked and shared.

**Templates:**
```
Lesson from Day [N]:

[What happened]
[Why it matters]
[What I'd do differently]
```
```
Things I wish I knew before [activity]:

1. [Lesson]
2. [Lesson]
3. [Lesson]

Would've saved me [time/money/pain].
```

**Examples for us:**
- "Gumroad takes 10%. Stripe takes 2.9%. I moved to my own site in one afternoon."
- "Don't run Opus for cron jobs. Haiku costs 95% less and runs bash scripts identically."
- "X API blocks replies to accounts you haven't engaged with. Semi-automated > full automation."

---

### Type 4: Thread (Deep Dive)
**Pattern:** Hook tweet → 3-7 main points → TL;DR recap → CTA
**Goal:** Establish authority. Threads get 3-5x the impressions of single tweets.

**Structure (Ship30for30 framework):**
1. **Lead-in tweet:** Grab attention. Who is this for? What do they get?
2. **Main points (3-7 tweets):** One idea per tweet. Each must stand alone.
3. **TL;DR tweet:** Summarize everything. For people who scrolled to the end.
4. **CTA tweet:** One clear action. Follow, link, reply.

**Rules:**
- First tweet must hook in 1.5 seconds
- Every tweet in the thread must be independently valuable
- Number your points (people love numbered lists)
- End with "Follow me for more [topic]" or a link

---

### Type 5: Engagement Tweet (Reply Bait)
**Pattern:** Question or controversial take that invites responses
**Goal:** Generate replies. Replies > retweets for algorithm boost.

**Templates:**
```
Hot take: [controversial opinion about your niche]

Change my mind.
```
```
What's the one tool you can't live without for [activity]?

I'll go first: [your answer]
```
```
Unpopular opinion: [take]

Here's why:
```

**Examples for us:**
- "Hot take: 90% of OpenClaw skills on ClawHub shouldn't be installed on anyone's machine."
- "What's the first thing you automate with an AI agent? I'll go first: security auditing."
- "Unpopular opinion: most AI 'products' are just markdown files with a price tag."

## The Weekly Schedule (7-Day Rotation)

| Day | Type | Content Focus |
|-----|------|--------------|
| Mon | Hook | Weekly insight or discovery |
| Tue | Proof | Real tool output / numbers |
| Wed | Lesson | Build-in-public learning |
| Thu | Thread | Deep dive on one topic |
| Fri | Engagement | Question or hot take |
| Sat | Proof | Weekly numbers recap |
| Sun | Off or light engagement reply |

## Posting Times (EST)
- **Primary:** 8:00-9:00 AM (morning scroll)
- **Secondary:** 12:00-1:00 PM (lunch break)
- **Tertiary:** 5:00-6:00 PM (commute scroll)

## The 280-Character Constraint Rules

1. **Front-load the hook** — first 50 chars decide if they stop scrolling
2. **One idea per tweet** — cramming two ideas = zero impact
3. **Line breaks > walls of text** — whitespace is a weapon
4. **Numbers > adjectives** — "$50" beats "a lot of money"
5. **No links in first tweet** — links suppress reach 20-50%
6. **Link goes in the reply** — post tweet, immediately reply with link

## Engagement Multipliers

- **Reply to every reply** in the first hour (signals active conversation)
- **Quote tweet** your own threads 2-3 days later with a new hook
- **Bookmark bait:** "Save this for later" in lessons/threads
- **Controversy is fuel:** Disagree with accepted wisdom (backed by evidence)
- **Time-on-tweet:** Longer tweets that people pause to read = algorithm boost

## What NOT to Do

- Don't tweet just links (link-only tweets get suppressed)
- Don't use more than 2 hashtags (looks spammy, doesn't help)
- Don't post and ghost — be in the replies for 30 min after posting
- Don't thread everything — singles with punchy hooks outperform lazy threads
- Don't ask for retweets explicitly (cringe and doesn't work)
- Don't copy other people's tweet formats word-for-word (people notice)

## Metrics to Track

- **Impressions:** Are people seeing you?
- **Engagement rate:** (likes + replies + retweets + bookmarks) / impressions
- **Reply rate:** Most important. Replies drive the algorithm.
- **Profile clicks:** Are people curious enough to check you out?
- **Link clicks:** Only matters for proof/CTA tweets.

**Benchmarks:**
- Good engagement rate: 2-5%
- Great engagement rate: 5-10%
- Viral territory: 10%+
- Good reply rate: 0.5-1%
- Thread impressions should be 3-5x your follower count
