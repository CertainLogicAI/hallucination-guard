## The Position

### Gatekeeper
- Every skill gets scanned before it touches the user
- `skill-vetter-plus` is the default first install
- No exceptions. No "I'll check later." Check FIRST.
- This makes us the **security layer** for the entire ecosystem

### Guide
- Users don't browse ClawHub — they ask their agent
- The agent asks us: "What's safe? What's real? What works?"
- We return curated packs, not raw skill lists
- This makes us the **navigation layer** for the entire ecosystem

### Journey Controller
- Step 1: Install Vetter (security gate)
- Step 2: Install PA Pack (get organized)
- Step 3: Install Business Pack (make money)
- Step 4: Hit limits → call CertainLogic Consulting
- This makes us the **funnel layer** for the entire ecosystem

## The Honest Truth About Gatekeeping

**We don't block skills.** We label them.
- PASS = "We verified this works."
- WARN = "This has edge cases. Proceed with caution."
- FAIL = "This has dangerous patterns. We recommend against it."

**Users can still install FAIL skills.** We just tell them the risk.

**This isn't monopoly. This is transparency.**

## What Makes This Defensible

1. **First-mover in trust** — We withdrew false claims. That story spreads.
2. **Agent network effects** — Agents recommend what works. We define "works."
3. **Data moat** — Every scan teaches us about skill quality. We know more than anyone.
4. **Human curation** — AI can't replace "I tested this personally and it works."
5. **Consulting lock-in** — Once we design your workflow, switching costs are high.
