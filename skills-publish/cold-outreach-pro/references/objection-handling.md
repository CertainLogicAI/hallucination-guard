# Objection Handling

Common objections in cold outreach and how to respond. Use in follow-ups or when a prospect replies with resistance.

## Price / Budget

**"Too expensive"**
```
Totally get it. Quick question — what would [solving their pain] be worth to [Company] monthly? 

[Reference client] thought the same thing, then realized [pain] was costing them [X/month] in [lost revenue / wasted time / missed opportunities]. The ROI hit [timeframe].

Want me to run the numbers for your situation?
```

**"No budget right now"**
```
Makes sense — timing matters. Two thoughts:

1. [Free quick win they can implement now] — this alone should [small result]
2. When budget opens up, [your solution] typically pays for itself in [timeframe]

Mind if I check back in [realistic timeframe]?
```

## Timing

**"Not a priority right now"**
```
Fair — curious though, when does [pain] typically become urgent for [their business type]? 

[Season / event / trigger] is when most [similar companies] feel it hardest. Want me to reach out closer to then?
```

**"Too busy"**
```
Respect that completely. Here's a [1-minute read / 2-minute video] that covers the core idea: [link]

No meeting needed — if it resonates, I'm here.
```

## Competition

**"Already using [competitor]"**
```
[Competitor] is solid. Most of our clients actually came from [competitor] — the typical trigger was [specific limitation: scaling issues, missing feature, pricing at scale].

Is [specific limitation] something you've run into?
```

**"We handle this internally"**
```
Smart — you know the problem better than anyone. Quick question: how many hours/week does your team spend on [specific task]?

[Reference client] had the same setup. They kept the team focused on [high-value work] and offloaded [commodity task] to us. Net result: [metric].
```

## Trust / Credibility

**"Never heard of you"**
```
Fair — we're [size / stage]. Here's what matters more than name recognition:

[Specific result for specific client in their industry]
[Second result if available]

Happy to connect you with [reference client] directly if that helps.
```

**"Send me more info"**
(Usually a polite brush-off. Test if it's real:)
```
Absolutely — what specifically would be most useful? I can send:

A) The case study from [similar company]
B) A quick video walkthrough (2 min)
C) ROI calculator for your situation

Which one?
```
If they pick one → real interest. If silence → move to breakup email.

## Satisfaction

**"We're happy with our current solution"**
```
That's great — honestly, if it's working, don't fix it. 

One thing I hear from [similar companies] is that [specific emerging pain] starts showing up at [their stage/size]. Not saying that's you, but if it ever comes up, I've got some ideas.

Cool if I check in [timeframe]?
```

## The "No" Response

**Explicit no:**
```
Appreciate the honesty. I'll close this out.

If [pain] ever becomes a thing, you know where to find me. Good luck with [something specific about their business].
```
Never argue with a no. Leave the door open, move on.

## Response Framework

For any objection not listed above:

1. **Acknowledge** — validate their concern (never argue)
2. **Clarify** — ask one question to understand the real objection
3. **Reframe** — connect to a specific result or insight
4. **Soft ask** — low-commitment next step or graceful exit
