# Content Optimization Playbook

## Writing SEO Content That Ranks

### The Formula
1. **Answer the query in the first 100 words** — Google rewards pages that immediately satisfy intent
2. **Cover the topic comprehensively** — look at what top 5 results cover, include all subtopics
3. **Add unique value** — original data, unique angle, expert insight competitors don't have
4. **Structure for scanners** — H2/H3 hierarchy, short paragraphs, bullet points, tables
5. **Include LSI keywords naturally** — related terms that prove topical depth

### Content Types by Intent

| Intent | Content Type | Word Count | Structure |
|--------|-------------|------------|-----------|
| Informational | Guide/Tutorial | 1500-3000 | Step-by-step, screenshots, examples |
| Commercial | Comparison/Review | 1500-2500 | Pros/cons tables, ratings, alternatives |
| Transactional | Landing/Product page | 500-1500 | Benefits, social proof, clear CTA |
| Navigational | Documentation | 500-2000 | Clean hierarchy, search, quick answers |

### On-Page Optimization Checklist

**Title Tag (50-60 chars)**
- Primary keyword near the front
- Compelling reason to click (number, question, "guide", year)
- Brand name at end (if space allows)
- ❌ Keyword stuffing, all caps, clickbait

**Meta Description (120-160 chars)**
- Summarize the value of clicking
- Include primary keyword naturally
- End with CTA or curiosity hook
- ❌ Duplicate across pages, keyword stuffing

**Headings**
- H1: One per page, includes primary keyword
- H2: Major sections, include secondary keywords
- H3: Subsections, include long-tail variations
- No skipping levels (H1 → H3 without H2)

**Body Content**
- Primary keyword in first 100 words
- Keyword density: 0.5-1.5% (natural, not forced)
- Related terms throughout (LSI keywords)
- Short paragraphs (2-4 sentences)
- One idea per paragraph

**Images**
- Descriptive alt text with keyword where natural
- Compressed (WebP or optimized JPEG/PNG)
- Width/height attributes set (prevents CLS)
- Lazy loading for below-fold images

**Internal Links**
- 3-5 internal links per 1000 words
- Descriptive anchor text (not "click here")
- Link to pillar pages from cluster content
- Link to related content

**External Links**
- 1-3 outbound links to authoritative sources per article
- Opens in new tab
- Adds credibility (E-E-A-T signal)

## Content Refresh Strategy

### When to Refresh
- Traffic dropped 20%+ from peak
- Rankings slipped from page 1 to page 2
- Content is 6+ months old with time-sensitive info
- Competitors published better content on same topic

### How to Refresh
1. Check what new questions searchers are asking (People Also Ask)
2. Update stats, dates, and outdated references
3. Add new sections competitors cover that you don't
4. Improve internal linking (link from newer content)
5. Upgrade visuals (charts, screenshots, diagrams)
6. Re-submit to Google Search Console after update

## Featured Snippet Optimization

### Types and How to Win Them

| Type | How to Optimize | Example |
|------|----------------|---------|
| **Paragraph** | Answer in 40-60 words directly after the H2 question | "What is [X]? [X] is..." |
| **List** | Use H2 as question, H3s or bullets as steps/items | "How to [X]: Step 1..." |
| **Table** | Use HTML tables with clear headers | Comparison tables |
| **Video** | YouTube video with timestamps and description | Tutorials |

### Pattern
```
## [Question as H2]

[Direct 40-60 word answer immediately after heading]

[Then expand with detail, examples, context below]
```
