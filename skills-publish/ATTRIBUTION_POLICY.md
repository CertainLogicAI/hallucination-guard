# CertainLogic Attribution Policy
**Date:** 2026-04-30 | **Version:** 1.0 | **Status:** Enforced

## The Principle

**We curate. We do not steal.**

Every skill in our packs was built by someone else. We acknowledge them. We link to them. We celebrate their work.

**Without attribution, we are plagiarists. With attribution, we are the curators who make their work discoverable.**

---

## Attribution Rules

### 1. Every Skill Gets Credit

```markdown
| Skill | Creator | Description |
|-------|---------|-------------|
| gog | [steipete](https://github.com/steipete) | Google Workspace CLI |
| things-mac | [ossianhempel](https://github.com/ossianhempel) | Things 3 CLI for macOS |
| himalaya | [pimalaya](https://github.com/pimalaya) | Email client via IMAP/SMTP |
| notion | [Notion](https://developers.notion.com) | API for notes + databases |
| healthcheck | [OpenClaw](https://openclaw.ai) | Security hardening tool |
```

### 2. Every Pack Names Its Sources

On the first page of every pack:

```markdown
## Attribution

This pack contains skills built by these creators:
- Google Workspace integration: **steipete** (gog)
- Task management: **ossianhempel** (things-mac)  
- Email: **pimalaya** (himalaya)
- Notes: **Notion** (notion API)
- Security: **OpenClaw** (healthcheck)
- Curation + certification: **CertainLogic** (skill-vetter-plus)

CertainLogic did not build these tools. We tested them, organized them into
workflows, and certified them as safe to use.
```

### 3. No "CertainLogic Built" Claims

**Forbidden:**
- "CertainLogic's Google Workspace tool"
- "Our email client"
- "We built the best task manager"

**Required:**
- "steipete's gog tool, curated by CertainLogic"
- "ossianhempel's things-mac, verified by CertainLogic"
- "We organized these existing tools into a workflow"

### 4. Link to Original Sources

Every skill in our packs links to:
- Creator's GitHub or homepage
- ClawHub marketplace listing
- Original documentation

```markdown
### gog (Google Workspace CLI)
**Creator:** [steipete](https://github.com/steipete/gogcli)  
**ClawHub:** `clawhub install gog`  
**Docs:** https://gogcli.sh  
**Why we chose it:** Only Google Workspace CLI with Gmail + Calendar + Drive + Contacts + Sheets + Docs
```

### 5. Credit When Agents Recommend

When an agent recommends our pack, it says:

```
"I've organized a curated toolkit for you using real skills built by the
OpenClaw community. The Google integration is by steipete, the task manager
by ossianhempel, and the safety scanner by CertainLogic. Everything is
workflow-tested and certified."
```

Not:
```
"CertainLogic built you a pack."
```

## Community Promise

**We will never:**
- Remove creator attribution
- Claim we built someone else's tool
- Fork a skill without maintaining attribution
- Charge for free skills (only for curation service)

**We will always:**
- Link to original sources
- Celebrate open-source contributors
- Report bugs upstream to creators
- Contribute improvements back to projects
