## Cache Performance Benchmark — 2026-05-07 19:01 EDT

**Benchmark:** Same query twice via `brain_wrapper.query()`

| Run | Latency | Path |
|---|---|---|
| 1st (uncached) | **736ms** | Full gbrain CLI → PGLite → search → parse |
| 2nd (cached) | **8ms** | Intent cache hit + query cache hit |
| **Speedup** | **88×** | — |

**Assessment:**
- Cache hit latency (8ms): **Well under 50ms target** ✅
- Uncached latency (736ms): **Above 500ms scope target** ⚠️, but not critical with cache
- Mitigation: Cache covers repeated queries; common case is fast

**Risk:** If hit rate stays low (many unique queries), average latency stays high.
**Action:** Track cache hit rate via `brain_metrics.py`. If hit rate <50% consistently, optimize uncached path (PGLite tuning, query simplification, or lighter search pattern).

**Status:** Production-viable. Monitor hit rate.
